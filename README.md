# PSC-DM website

Complete static website for the PSC-DM calculator.

Files:
- `index.html`
- `style.css`
- `script.js`
- `.nojekyll`

Upload all four files to the root of your GitHub repository.

## GitHub Pages
1. Open the repository.
2. Go to Settings → Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select `main` and `/ (root)`.
5. Save.

The site will then be available at an address similar to:
`https://YOUR-USERNAME.github.io/psc-dm/`

The calculator runs locally in the browser. No patient data are transmitted or stored.
